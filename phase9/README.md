# Phase 9 Foundation Package

This package contains the Phase 9 foundational modules required across the reporting and packaging pipeline: configuration, utilities, logging, exceptions and JSON schemas.

Purpose
- Provide a stable, production-ready foundation used by subsequent Phase 9 modules.

Modules included
- `phase9.config` — configuration loader and settings.
- `phase9.utils` — generic filesystem, checksum, JSON/YAML helpers.
- `phase9.logging` — structured JSON logging configuration.
- `phase9.exceptions` — centralized exception hierarchy.
- `phase9.schemas` — canonical JSON Schema definitions used by Phase 9.
